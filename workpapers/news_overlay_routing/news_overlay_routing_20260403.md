# 新闻非行业 Overlay 分流说明

- 日期：`2026-04-03`
- 目的：先把明显不该硬塞进行业 backbone 的新闻分流出去，再看真正需要补行业映射的剩余样本。

## 第一版分类

- `宏观数据/经济指标`
  - 关键词：`PMI / CPI / PPI / GDP / 就业市场 / 服务业活动 / 制造业活动`
- `地缘冲突/战争扰动`
  - 关键词：`伊朗 / 美军 / 战斗机 / 霍尔木兹海峡 / 停火 / 被击落 / 防空警报`
- `财政预算/部门拨款`
  - 关键词：`财年预算 / 预算方案 / 自由支配预算 / 拨款 / 预算权限 / 关税收入`
- `公共事务/纪检治理`
  - 关键词：`违纪违法 / 纪律审查 / 监察调查`
- `综合快讯栏目`
  - 关键词：`国内联播快讯 / 国际联播快讯`

## 当前效果

基于 `news_source_mapping_latest` 本地快照：

- `news_cctv`
  - `raw_unmatched = 3`
  - `overlay_hit = 2`
  - `true_unmatched = 1`
- `stock_info_global_cls`
  - `raw_unmatched = 11`
  - `overlay_hit = 8`
  - `true_unmatched = 3`
- `stock_info_global_em`
  - `raw_unmatched = 84`
  - `overlay_hit = 38`
  - `true_unmatched = 46`

这意味着当前新闻层已经可以把一大批“本来就不是行业事件”的新闻先筛掉，后续行业词表和主题词扩展会更干净。

另外，这一轮还把评估脚本和 runtime 的 `theme overlay keywords` 对齐了，并新增了：

- `商业航天链`
  - 关键词：`商业航天 / 航天 / 火箭 / 运载火箭 / 卫星 / 金色穹顶`

这让 `快舟十一号遥十三运载火箭通过出厂质量评审` 这类标题，不再长期挂在“真未命中”里。

## 当前还剩下的真未命中

这一轮分流之后，剩余样本更集中在这几类：

- `航天军工主题`
  - 例：`快舟十一号遥十三运载火箭通过出厂质量评审`
- `海外商品 / 产业公司事件`
  - 例：`阿联酋环球铝业公司：恢复阿布扎比铝产量可能需时长达一年`
- `公司法务 / 监管 / 风险提示`
  - 例：`将被实施其他风险警示 山东章鼓4月7日停牌一天`
- `跨国外交访问 / 反垄断 / 泛国际事务`

## 下一步建议

- 不继续盲目扩一级行业 `heat_keywords`
- 先补：
  - `theme overlay`
  - `监管 / 风险提示` 轻量分流
  - 必要时再补 `机构名 / 公司名 -> 行业`
- `news_keyword_candidates` 默认只基于 `true_unmatched_titles` 生成，不再把宏观 / 地缘 / 预算词继续往行业词表里推
