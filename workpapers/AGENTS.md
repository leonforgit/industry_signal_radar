# AGENTS.md

This directory is the support layer for scans, source maps, backlog notes, and experiment drafts.

## Default Rule

- Put external scans, temporary comparisons, source manifests, and unresolved questions here.
- Do not treat `workpapers/` as a second home for final conclusions that belong in `reports/main.md`.
- If a point becomes durable and decision-useful, merge it back into the main report.
