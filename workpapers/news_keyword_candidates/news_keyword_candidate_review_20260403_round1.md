## 2. Reject / Avoid (明确不推荐)

以下关键词**看似相关但风险高于收益**，应明确避免加入行业词表。

| 关键词/模式 | 出现频次 | 拒绝理由 |
|------------|---------|---------|
| `亿元` / `万元` / `万亿美元` | 高频 | 纯数值单位，无行业指向性。如加入会污染几乎所有行业 |
| `2025` / `2026` / `2027` / `Q1` | 高频 | 时间标识，跨全行业均匀分布，无区分度 |
| `特朗普` / `川普` / `Trump` | 中频 | 政治人物，新闻中横跨政策/地缘/宏观多维度，强行绑定任何单一行业都会引入噪声 |
| `NASA` / `国家航空航天局` | 1 | 机构名，关联国防军工但同时也是民用航天/科研，样本中涉及预算拨款，属政策事件而非行业经营信号 |
| `Wegovy` / `orforglipron` / `司美格鲁肽` | 1 | 具体药品商品名，过于细分且随专利周期快速过时。医药生物行业已有`化学制药`、`生物制品`等更稳定的上位词 |
| `准油股份` / `诺和诺德` / `台积电` / `山东章鼓` 等 | 多 | 公司名，应通过公司→行业映射表处理，不应硬编码进关键词 |
| `业绩预告` / `一季度净利` / `同比增长` | 中频 | 财务通用表述，A股全行业公司都会发布，无行业区分度 |
| `立案` / `停牌` / `ST` / `退市风险警示` | 中频 | 监管/合规事件，虽在资本市场上高频，但属于全市场通用概念，不特定于某一行业 |
| `AI` / `人工智能` / `生成式人工智能` | 中频 | 过于宽泛，当前已渗透全行业（计算机、传媒、汽车、医药、金融）。如需细分，建议等`AI+医疗`、`AI+自动驾驶`等垂直组合词出现 |
| `中小企业` / `服务业` / `PMI` | 低频 | 宏观/统计口径概念，非行业级经营信号，更适合宏观overlay层处理 |
| `增持` / `减持` / `募资` / `定向增发` | 低频 | 资本运作通用行为，跨行业普遍存在 |
| `停火` / `空袭` / `击落` / `武装` | 低频 | 已有`军工`、`军队`、`导弹`等更稳定词覆盖，这些动作词单独出现可能引入非军事噪声 |

## 4. 审阅结论与建议

### 4.1 本轮可执行动作

1. **立即追加**: `霍尔木兹海峡` → 交通运输 + 石油石化
2. **考虑追加**: `先进制程` → 电子（如确认现有`半导体`词未覆盖该细分场景）
3. **暂不处理**: 其余候选词

### 4.2 系统改进建议

1. **建立主题链层**: 当前系统只有"一级行业-关键词"单层映射，建议增加第二层"主题/事件链"，处理地缘政治、政策、宏观、技术跨界等场景
2. **公司名映射**: 多个未命中标题因包含公司名（准油股份、诺和诺德等）而未匹配，建议建立`公司名称→行业代码`辅助映射表
3. **过滤词表**: 建议建立全局`stopwords`过滤`亿元`、`2025`、`一季度`等高频无意义片段，减少候选池噪声

### 4.3 风险提醒

- 当前 `akshare:stock_info_global_em` 未命中率高达 **54.5%** (109/200)，部分源于标题过于侧重公司个体而非行业
- 若强行追加低置信关键词以提高命中率，可能牺牲行业热度的纯净性
- 建议优先完善**公司→行业映射**和**主题链分层**，而非单纯扩充关键词表
