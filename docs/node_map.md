# 节点地图

## 1. 节点设计原则

这个项目不按“单模型”推进，而按“节点化”推进。

每个节点都要回答 4 个问题：

- 它看什么现象
- 它依赖什么数据
- 它输出什么结构
- 它在哪些情况下最容易失真

## 2. 一级节点

### 节点 0：行业对象层

要回答：

- 行业怎么定义
- 主题和行业如何映射
- 龙头和代表标的如何选择

输出：

- 行业清单
- 别名表
- 标的映射表

### 节点 1：资金层

要回答：

- 早期资金是否开始向某个行业集中
- 龙头是否领先于板块扩散
- 板块成交结构是否发生变化

输出：

- 行业资金强弱信号
- 龙头牵引信号
- 扩散度信号

### 节点 2：基本面层

要回答：

- 行业经营状态是否出现边际改善
- 变化来自价格、需求、供给、库存、盈利还是政策
- 哪些变量对该行业最领先

输出：

- 行业经营状态代理信号
- 行业专属先行指标地图

### 节点 3：新闻层

要回答：

- 行业相关新闻是否明显增多
- 新闻是否开始从零散传闻转为高密度叙事
- 来源是否扩散到券商、产业媒体、政策口径

输出：

- 新闻热度信号
- 主题聚类
- 叙事收敛 / 分歧信号

### 节点 4：政策 / 预期层

要回答：

- 是否出现新的政策催化、制度变化或预期修正
- 这些变化是否具有行业级传导意义

输出：

- 政策催化信号
- 预期修正信号

### 节点 5：技术 / tape 层

要回答：

- 市场是否开始用价格结构确认行业逻辑
- 是底部抬升、突破、反弹还是短期脉冲

输出：

- 价格结构信号
- 量价确认信号

### 节点 6：评分与状态机层

要回答：

- 多节点信号如何合成
- 行业状态如何迁移
- 证据链如何保留可解释性

输出：

- 行业状态
- 状态变化原因
- 核心证据链

### 节点 7：历史验证层

要回答：

- 哪些节点真的领先
- 哪些只是事后解释
- 假启动和失败样本有哪些共性

输出：

- 历史标签集
- 验证结果
- 节点保留 / 下线建议

## 3. 节点推进顺序

默认先细化：

1. 行业对象层
2. 起势定义与标签层
3. 基本面层
4. 新闻层
5. 资金层
6. 评分与状态机层
7. 历史验证层
